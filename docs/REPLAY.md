# Replay: does waiting for the cleanest hours really cut CO2?

Generated by `npm run replay` from `data/gb-history.json`: 17520 half-hours of Great Britain national carbon intensity, 2025-11-01 to 2026-10-31, from the NESO Carbon Intensity API (CC BY 4.0). 1 half-hour(s) repaired (an actual of 0 g while the forecast said 62 g; the forecast value is used).

Method: every day, the appliance could start at the habit time. Grid Tide picks the start inside the window from the **forecast**; both runs are then scored on the **actual** intensity (NESO's after-the-fact estimate, not the forecast). "Hindsight" is the best start knowing the actuals (an upper bound).

## Limits

- The history keeps the last forecast made for each half-hour. A forecast made at 19:00 for 03:00 is less accurate, so live savings can be a little lower than the "Cut" column (the gap between Cut and Hindsight shows how much forecast error costs).
- Intensity here is the **average** of the grid mix. The CO2 a shifted load really avoids depends on the **marginal** plant, which is usually gas in GB at peak times; at windy night-time hours some of the extra demand is met by wind that would otherwise be curtailed. Average intensity is the standard public signal (it is what the NESO API and most smart tariffs use), but treat the kg figures as an estimate, not a meter reading.
- National series only: regional history has no actual values.
